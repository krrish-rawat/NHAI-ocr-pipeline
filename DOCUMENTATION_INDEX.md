## Key Concepts Explained

### Document Validation System
- **Where:** `VALIDATION_CODE_REFERENCE.md` or `VALIDATION_SYSTEM_READY.md`
- **What:** Pre-extraction gate that blocks invalid documents
- **Why:** Prevents wasting API calls and processing time

### Accepted Document Types
- **Where:** `ACCEPTED_DOCUMENT_TYPES.md`
- **List:** LOA, CC, PCC, Financial Closure, Debarment Records, Debarment of Individuals
- **Whitelist Location:** `/src/services/extraction_service.py`

### Processing Pipeline
- **Where:** `PROJECT_DOCUMENTATION.md` → Processing Pipeline
- **Steps:** Classification → Validation → OCR → Extraction → Summary
- **Phases:** Phase 1 (classify), Phase 2 (validate), Phase 3 (OCR), Phase 4 (extract)

### API Response Structure
- **Where:** `PROJECT_DOCUMENTATION.md` → API Endpoints
- **Contains:** attributes, records, document_validity
- **Key:** document_validity tells frontend if document is valid

### Frontend Validation Gate
- **Where:** `/static/app.js` (lines 1162-1195)
- **Does:** Checks document_validity before showing results
- **Why:** Prevents showing results for blocked documents
